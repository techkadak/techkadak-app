# Install Tech Kadak

## First install

1. Open the [latest release](https://github.com/techkadak/techkadak-app/releases/latest) on your phone.
2. Under **Assets**, tap the file that ends in `.apk` and download it.
3. Open the downloaded file.
4. If Android shows *For your security, your phone is not allowed to install unknown apps from this source*, tap **Settings** and switch on **Allow from this source** for your browser or file manager. Go back.
5. Tap **Install**, then **Open**.

The exact steps and wording differ a little between phone brands (Oppo, Xiaomi, Samsung and others).

## Update

- **In the app:** when a new version is out, an update card appears. Tap **Update**. If you tap *Later*, it reminds you again next time.
- **By hand:** download the newest APK from the [latest release](https://github.com/techkadak/techkadak-app/releases/latest) and install it over the old one. Your data stays.

## Troubleshooting

| Problem | What to try |
|---|---|
| "App not installed" | Make sure you downloaded the whole file. Uninstall a copy that came from somewhere else, then install again. |
| "Install blocked" | Allow installs from your browser or file manager (step 4 above). |
| App crashed | Open it again. If a pop-up offers *Report copy karo*, send the text to [Telegram](https://t.me/techkadak). |
| Update card does not show | Check your internet and open the app again. Or install the latest APK by hand. |

## Requirements

Android 7.0 or newer. About 5 MB of space.
