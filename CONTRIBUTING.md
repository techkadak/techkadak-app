# Contributing to Tech Kadak

This repository holds the **releases, documentation and release notes** of the Tech Kadak Android app. The app's source code is not published here, so this is not the place for code pull requests.

## What helps most

- **Suggest an app.** Send the app's name and its official link on [Telegram](https://t.me/techkadak). It must be free or open-source and have an official source (GitHub, F-Droid or the developer's website).
- **Report a bug.** Open an [issue](https://github.com/techkadak/techkadak-app/issues) or message us on Telegram with your phone model, Android version, app version and what happened. If the app showed *Report copy karo*, include that text.
- **Request a feature.** Use the bulb at the top of the app, or tell us on Telegram.
- **Fix our docs.** A typo or an unclear step in the README or `docs/`? Send a pull request or an issue.

## Ground rules

- Official links only. No mirrors and no modified APKs.
- Be kind. We read everything.
